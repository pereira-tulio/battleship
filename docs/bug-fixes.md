# Bug fixes and risk validation

These entries are based on implementation review and the regression tests
listed in the final column.

| Bug/risk identified                                                   | How reproduced or detected                                                      | Root cause                                                            | Fix implemented                                                                                | How validated                                                          |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Reducer could make divergent AI decisions in StrictMode               | Code review found `Date.now()` inside the `ai-fire` reducer branch              | Reducers must be pure, and StrictMode may invoke them more than once  | State now carries an incrementing seed; AI receives a deterministic RNG derived from that seed | `battleshipReducer` deterministic state test and UI fake-timer flow    |
| Hunt parity used the largest remaining ship                           | Code review compared the implementation with the stated minimum-length strategy | Candidate mask used `Math.max` instead of the smallest live ship size | Hunt mode now derives parity from the minimum remaining length                                 | `uses the minimum remaining ship length for hunt parity`               |
| Only the final sunk cell was marked sunk                              | Combat review and a renderer inspection showed previous cells remained `hit`    | `fireAt` only wrote the latest shot key                               | A sunk result marks every cell in that ship as `sunk`                                          | `reports miss, hit, sunk and win` checks both ship cells and UI labels |
| Keyboard navigation could dead-end on fired cells                     | Code review found fired cells were disabled before arrow navigation             | Disabled buttons cannot receive focus                                 | Cells remain focusable and use `aria-disabled`; activation is a no-op when locked              | Board navigation helper tests and UI grid flow                         |
| Grid ARIA structure was invalid                                       | Accessibility review found 100 direct gridcell children                         | ARIA grids require row grouping                                       | Boards now render ten `role="row"` wrappers                                                    | UI test queries semantic grids and rendered rows                       |
| Player fleet remained wired for interaction during play               | Code review found the player board always received placement callbacks          | Board interaction was not phase-gated                                 | `interactive` is true only during placement; firing is enabled only on player turn             | Full UI flow verifies phase-specific actions                           |
| Stale AI timeout could land after New Game                            | Fake-timer scenario was identified during reducer/hook review                   | A queued timeout could dispatch after a reset                         | Timer cleanup plus reducer phase guards prevent stale actions                                  | UI flow advances timers after New Game and verifies zero hits taken    |
| Vertical and negative placement boundaries were easy off-by-one cases | Boundary-focused placement tests                                                | Validation must inspect every generated cell, not only its origin     | `canPlaceShip` validates all generated coordinates                                             | Placement orientation/boundary cases in `game.test.ts`                 |
